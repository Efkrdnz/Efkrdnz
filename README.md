## How I build

For content-heavy projects, I prefer registry-driven data, reusable components, centralized validation, and a clear separation between gameplay state, networking, and presentation. This makes new abilities, quests, items, and entities easier to add without duplicating logic.

I am currently expanding from Minecraft modding into broader gameplay programming and building tools that make development workflows faster and easier to maintain.
